\section{Introduction}
\label{sec:5_intro}

This chapter prepares the aligned point cloud from Chapter~\ref{ch:4_Alignment_Updating} for the parallel scene and object completion stages through two complementary analyses: object isolation and occlusion detection. 

Object isolation decomposes the scene into structural background elements and individual foreground objects. Since standard 3D detectors fit bounding boxes only to the visible geometry~\cite{qi_deep_2019}, partially scanned objects yield boxes that are too small or misoriented for the downstream completion methods, which require properly bounded and aligned partial observations~\cite{vermandere_guided_2025, mittal_autosdf_2022}. A refinement step is therefore applied that uses detected symmetry axes and physical constraints from adjacent scene planes to correct the bounding box orientation and extent prior to completion.

Occlusion detection then determines which regions of the scene were hidden from the scanner rather than genuinely empty, a distinction that is critical for guiding the completion stages without hallucinating geometry in observed free space. The analysis is performed at two levels simultaneously: a scene-level grid classifying the full room volume for the scene completion in Chapter~\ref{ch:6_Scene_Completion}, and per-object grids classifying the volume within each refined bounding box for the object completion in Chapter~\ref{ch:7_Object_Completion}.

\section{Related Work}
\label{sec:5_related}

This section reviews the four areas of prior work most relevant to the contributions of this chapter: 3D object detection in point clouds, symmetry detection in partial geometry, plane segmentation for structural element extraction, and occlusion detection and reasoning in scanned environments.


% ─────────────────────────────────────────────────────────────────────────────
\subsection{3D Object Detection}
\label{sec:5_rw_detection}

Detecting objects directly in 3D point clouds has received considerable attention in recent years, driven by the availability of large-scale annotated indoor datasets such as ScanNet~\cite{dai_scannet_2017} and SUN RGB-D~\cite{song_sun_2015}. VoteNet~\cite{qi_deep_2019} introduced an end-to-end architecture that combines deep point set feature learning with a Hough voting mechanism. Each input point generates a vote for potential object centres, and these votes are aggregated into clusters from which bounding box parameters are predicted. VoteNet demonstrated that purely geometric information, without relying on colour images, is sufficient for competitive 3D detection on real scans. Subsequent works refined this paradigm: MLCVNet~\cite{xie_mlcvnet_2020} introduced multi-level contextual information through patch-to-patch, object-to-object and global scene context modules, improving detection accuracy by capturing relationships between objects rather than treating them independently. VoteNet+~\cite{ding_votenet_2020} further refined the voting mechanism through architectural improvements.

More recently, transformer-based approaches have gained prominence. V-DETR~\cite{shen_v-detr_2023} adapts the DETR detection framework to 3D by introducing vertex-relative positional encoding, which improves the locality of attention mechanisms and addresses the tendency of earlier transformer detectors to attend to distant, irrelevant points. UniDet3D~\cite{kolodiazhnyi_unidet3d_nodate} explores unified training across multiple indoor datasets by extracting point features using sparse 3D U-Nets, aggregating them via superpoint pooling, and employing a vanilla transformer encoder for object prediction. AIC3DOD~\cite{cheng_aic3dod_nodate} addresses class-incremental detection by incorporating point transformer architectures alongside room layout constraints, enforcing physical priors derived from the scene structure to improve robustness in incremental learning settings.

For instance-level understanding, SphericalMask~\cite{shin_spherical_2023} proposes a coarse-to-fine segmentation strategy based on spherical representations, avoiding the overestimation issues common in axis-aligned bounding boxes. UnScene3D~\cite{rozenberszki_unscene3d_2023} introduces a fully unsupervised pipeline for class-agnostic 3D instance segmentation by generating pseudo-labels from self-supervised geometric and colour features. Mask3D~\cite{schult_mask3d_2022} applies transformer-based instance segmentation using learned instance queries that directly predict instance masks from point cloud features at multiple scales.

Despite these advances, all of these methods detect objects based on the geometry that is \textit{present} in the scan. They do not predict the spatial extent of the object beyond what is visible, which means the resulting bounding boxes are fitted to the partial observation rather than to the estimated complete object. This limitation necessitates a post-detection refinement step.


% ─────────────────────────────────────────────────────────────────────────────
\subsection{Symmetry Detection}
\label{sec:5_rw_symmetry}

Symmetry detection in 3D shapes provides geometric cues that can be used to infer the orientation, centre and spatial extent of partially observed objects. Most manufactured indoor objects exhibit at least one axis of symmetry due to design and manufacturing constraints, making symmetry a useful prior for bounding box refinement.

For complete objects, PRS-Net~\cite{gao_prs-net_2019} employs a learning framework to automatically discover global planar reflective symmetry by training an unsupervised 3D convolutional neural network to extract global model features. However, complete geometry is rarely available for scanned objects.

Partial symmetry detection is more challenging because there is no guarantee that symmetrical features will be captured. Mitra et al.~\cite{mitra_partial_2006} developed an early algorithm that processes geometric models and efficiently discovers and extracts a compact representation of their Euclidean symmetries, handling both partial and approximate symmetry. The method is based on matching simple local shape signatures in pairs and accumulating evidence for symmetries in an appropriate transformation space. Sipiran et al.~\cite{sipiran_approximate_2014} improved upon this with a vote-based approach specifically targeting partial 3D meshes with large missing parts. Their algorithm generates candidate symmetries by matching local maxima of a surface function based on heat diffusion in local domains, providing robustness to missing data. A multi-scale surface function selects distinctive points over which approximate symmetries are defined, and a partiality-aware voting scheme reduces false positive detections. SymmetryNet~\cite{shi_symmetrynet_2020} requires only a single RGB-D input to discover global planar reflective symmetry using an unsupervised 3D convolutional network.


% ─────────────────────────────────────────────────────────────────────────────
\subsection{Plane Segmentation}
\label{sec:5_rw_planes}

RANSAC-based plane detection remains the most widely used approach for extracting planar primitives from point clouds. The basic algorithm randomly samples minimal point subsets to generate plane hypotheses and evaluates them against the full point set to identify inliers. Latent RANSAC~\cite{korman_latent_2018} accelerates hypothesis evaluation by learning to score RANSAC hypotheses in constant time, enabling efficient detection of dominant planar structures. Li et al.~\cite{li_improved_2017} proposed an improved RANSAC method based on Normal Distribution Transformation cells to avoid spurious planes in noisy data. Nurunnabi et al.~\cite{nurunnabi_robust_2016} introduced robust diagnostic principal component analysis for plane segmentation that handles outlier- and noise-contaminated data more effectively than standard RANSAC.

For indoor environments specifically, several works exploit the structural regularity of buildings. Jung et al.~\cite{jung_automated_2016} use constrained least-squares adjustment to produce wireframe models of indoor structures, enforcing the assumption that walls, ceilings, floors, doors and windows are composed of lines that are either parallel or orthogonal. Budroni and Boehm~\cite{budroni_automatic_2010} developed an automatic technique for reconstruction of Manhattan-world interior scenes using a volume sweep approach. Nikoohemat et al.~\cite{nikoohemat_exploiting_2017, nikoohemat_change_2018} combine plane detection with trajectory-based occlusion reasoning to detect openings and reconstruct walls, floors and ceilings in cluttered indoor environments captured by mobile laser scanners.


% ─────────────────────────────────────────────────────────────────────────────
\subsection{Occlusion Detection}
\label{sec:5_rw_occlusion}

Chen et al.~\cite{chen_dynamic_2016} proposed a dynamic occlusion detection and inpainting method for sequential terrestrial laser scanning point clouds. Their approach establishes a panoramic space partition that assigns a three-dimensional voxel to each laser point according to the scanning setup, then constructs stationary background models using laser reflectance intensity and geometrical attributes across a TLS sequence. This method achieves high precision and recall for dynamic occlusion detection but requires multiple sequential scans from the same position.

Nikoohemat et al.~\cite{nikoohemat_exploiting_2017, nikoohemat_change_2018} demonstrate the value of the scanner trajectory for occlusion reasoning in indoor mobile laser scanning. By using the trajectory as a set of scanner positions, gaps can be discriminated from real openings in the data, and a voxel-based method can be applied for labelling navigable space and separating it from obstacles. Their results show that the trajectory plays an essential role in understanding indoor scenes.

In the context of scene de-occlusion from images, Zhan et al.~\cite{zhan_self-supervised_2020} propose a self-supervised framework for recovering hidden scene structures, including progressive ordering recovery, amodal completion and content completion. While this operates on 2D images rather than 3D point clouds, it demonstrates the broader principle that occlusion reasoning is essential for producing complete scene representations. For object-level occlusion reasoning, Co-Section~\cite{strecke_where_2020} uses an object-level dynamic SLAM frontend to detect, segment, track and map dynamic objects, then completes their shapes using hull and intersection constraints between objects and scene surfaces. This is conceptually related to the approach in this chapter, where detected scene planes provide intersection constraints that inform both bounding box refinement and occlusion estimation. Zhu et al.~\cite{zhu_occlusion_2020} address occlusion handling for industrial robots through occlusion-aware optimal sensor positioning and event-driven occlusion detection, demonstrating that occlusion reasoning is critical not only for reconstruction but also for planning and safety applications.

The approach proposed in this chapter differs from the above works in that it performs occlusion detection through voxelised ray marching from the known scanner position(s), operating at two levels simultaneously: scene-level occlusion for the entire room, and object-level occlusion within each detected oriented bounding box. This dual-level approach provides the information needed by both the scene completion stage (Chapter~\ref{ch:6_Scene_Completion}) and the object completion stage (Chapter~\ref{ch:7_Object_Completion}).

\section{Methodology}
\label{sec:5_methodology}

The methodology consists of two main components: object isolation (Section~\ref{sec:5_object_isolation}) and occlusion detection (Section~\ref{sec:5_occlusion_detection}). Object isolation begins with a structural segmentation of the scene through iterative plane extraction, followed by object detection on the cleaned point cloud, symmetry detection on the isolated objects, and bounding box refinement using the detected symmetry axes and scene planes. Occlusion detection then determines which parts of the scene and of each individual object were hidden from the scanner. \subsection{Object Isolation}
\label{sec:5_object_isolation}

The object isolation process consists of four sequential steps: plane-based structural segmentation of the scene, 3D object detection on the remaining foreground points, symmetry detection on the isolated partial objects, and bounding box refinement using the symmetry axes and structural planes.


% ── 5.3.1.1 ──────────────────────────────────────────────────────────────────
\subsubsection{Plane-Based Structural Segmentation}
\label{sec:5_plane_detection}

The first step in object isolation is to separate the structural elements of the scene from the foreground objects. Indoor environments are predominantly composed of large planar surfaces such as walls, floors and ceilings, and these can be efficiently detected and removed before the object detection stage. Removing the structural geometry serves two purposes: it reduces the input complexity for the object detector by eliminating the dominant surfaces that are not objects of interest, and it produces the set of structural planes that will later be used to constrain the bounding box refinement.

The structural segmentation is performed through a sequential iterative RANSAC plane detection~\cite{korman_latent_2018} on the full scene point cloud. At each iteration, the largest plane containing more than a predefined minimum number of inlier points is extracted and its inliers are removed from the remaining point set. The procedure is repeated until no planes with a sufficient number of inliers remain. After the procedure is complete, only a small number of residual points remain that do not fit any detected plane.

A simple semantic classification is then applied to each detected plane based on its normal direction. Planes with normals approximately aligned with the vertical axis are classified as floors or ceilings depending on their height, while planes with approximately horizontal normals are classified as walls. The points belonging to classified floor, wall and ceiling planes are removed from the scene, leaving predominantly foreground object geometry for the subsequent detection step.

To define proper physical boundaries for later use in bounding box refinement, the intersections between the detected planes are computed and used to define boundary quads. These boundaries, together with the plane normals, provide the geometric constraints that will limit the extent of the refined bounding boxes in Section~\ref{sec:5_bb_refinement}~\cite{vermandere_guided_2025}.

\subsubsection{3D Object Detection}
\label{sec:5_detection}

Object detection is performed on the cleaned point cloud, from which the structural planes have already been removed. A VoteNet-style detector~\cite{qi_deep_2019} is used, operating directly on the point cloud rather than on images. The choice of a point cloud-based detector is motivated by the fact that point cloud observations typically exhibit fewer occlusions compared to image-only inputs, as a single scan captures the full 360-degree environment from the scanner position. Since the detection network requires a point cloud as input, the scene is first sampled to a uniform resolution of 5\,cm, providing a suitable balance between geometric detail and execution speed~\cite{vermandere_guided_2025}.

The detection mechanism operates through a centre density estimation. Each input point $\mathbf{x}_i$ is mapped to a vote $\mathbf{v}_i$ by first extracting features $\phi(\mathbf{x}_i)$ and then predicting a centre offset using a trained voting function $g(\cdot)$:

\begin{equation}
    \label{eq:5_voting}
    \mathbf{v}_i = \mathbf{x}_i + g(\phi(\mathbf{x}_i))
\end{equation}

Votes are then aggregated to form proposal features from which bounding box parameters are predicted. To mitigate over-detection, which is a common tendency in indoor scenes where furniture is closely spaced, overlapping bounding boxes are merged when their Intersection over Union exceeds 80\%~\cite{vermandere_guided_2025}.

By performing the detection on the cleaned point cloud rather than the full scene, the detector can focus on the actual foreground objects without being distracted by the dominant structural surfaces. This is particularly important in scenes with large flat surfaces that could otherwise generate spurious detections or absorb votes intended for nearby objects.

After detection, the objects are isolated from the scene. Rather than removing only the visible surface points, all points within the full bounding box volume are removed to ensure clean separation between object geometry and the surrounding environment. This process results in an incomplete scene with large rectangular holes that can be reconstructed in a later stage by the scene completion pipeline (Chapter~\ref{ch:6_Scene_Completion}).

\subsubsection{Symmetry Detection}
\label{sec:5_symmetry_detection}

The bounding boxes produced by the object detector are axis-aligned and fitted only to the visible points of each object. For proper completion, the bounding box must be oriented according to the object's principal axes and expanded to approximate the full spatial extent of the complete object, including its occluded portions. The first step toward this refinement is detecting the symmetry axes of each partial object.

Most indoor objects exhibit at least one axis of symmetry due to manufacturing constraints. To exploit this property, approximate symmetry detection~\cite{sipiran_approximate_2014} is applied to the partial point cloud of each isolated object. The algorithm generates candidate symmetries by matching local maxima of a surface function based on heat diffusion in local domains, providing robustness to missing data. A multi-scale surface function selects distinctive points over which approximate symmetries are defined, and a partiality-aware voting scheme reduces false positive detections.

The detected symmetry planes provide two pieces of information that are essential for the subsequent bounding box refinement. First, the normal of the symmetry plane indicates one of the object's principal axes, which will be used as the ``right'' vector in the oriented bounding box construction. Second, the position of the symmetry plane provides an estimate of the object's geometric centre along that axis, enabling the bounding box to be centred symmetrically around the detected plane rather than being fitted only to the observed portion.

As observed in~\cite{vermandere_guided_2025}, proper alignment of the object has the greatest impact on the quality of subsequent completion results. When objects are not properly aligned, the completion network struggles to interpret the input and tends to produce distorted shapes. Even for objects with known boundaries, the network fails to complete the object meaningfully without proper orientation. This underlines the importance of the symmetry detection step within the overall pipeline.

\subsubsection{Bounding Box Refinement}
\label{sec:5_bb_refinement}

The final step of the object isolation process combines the detected symmetry axis with the structural planes from the scene segmentation to construct a refined oriented bounding box for each object. The refinement proceeds in two stages: orientation estimation and boundary limiting.

\paragraph{Orientation estimation.}
The oriented bounding box is constructed by combining the symmetry axis with the structural planes detected in Section~\ref{sec:5_plane_detection}~\cite{vermandere_guided_2025}. First, the adjacency of the object to each detected scene plane is computed to determine whether the object is grounded on the floor or mounted against a wall. The normal of the adjacent plane defines the first rotation axis, labelled as ``up''. For an object standing on the floor, this is the floor normal; for a wall-mounted object, it is the wall normal. The symmetry axis then defines the second rotation axis, the ``right'' vector, as the normal of the detected symmetry plane. Together, these two vectors define a unique rotation that is used to orient the bounding box around the incomplete object.

\paragraph{Boundary limiting.}
Once the orientation is established, the scene planes are used to constrain the spatial extent of the bounding box. The bounding box boundaries are limited so that they do not extend through detected walls, floors or ceilings, preventing the bounding box from including regions that are physically impossible for the object to occupy. The symmetry axis is further used to centre the bounding box: when a clear symmetry plane is found, the bounding box is made symmetric about this plane, effectively predicting the spatial extent of the unobserved portion based on the observed portion. When an object exhibits multiple symmetry axes, the alignment can be further refined~\cite{vermandere_guided_2025}.

This refinement step is particularly important for objects positioned against walls or in corners, where the scene planes provide strong geometric constraints. For freestanding objects, the refinement relies more heavily on the symmetry detection, which may be less reliable when only a small portion of the object is observed.

\subsection{Occlusion Detection}
\label{sec:5_occlusion_detection}

After object isolation and bounding box refinement, the next step is to determine which regions of the scene and of each individual object were occluded during scanning. This information is essential for the completion stages: scene completion (Chapter~\ref{ch:6_Scene_Completion}) needs to know where new environmental geometry should be reconstructed, and object completion (Chapter~\ref{ch:7_Object_Completion}) needs to know which parts of each object were hidden from the scanner.

The occlusion detection is performed through voxelised ray marching from the known scanner position(s). The approach operates at two levels: scene-level occlusion for the entire room, and object-level occlusion within each detected oriented bounding box.


% ── 5.3.2.1 ──────────────────────────────────────────────────────────────────
\subsubsection{Voxelised Ray Marching}
\label{sec:5_raymarching}

The core operation is a discrete ray traversal through a voxel grid. Given the scanner position $\mathbf{o}$ and the set of scanned points $P = \{\mathbf{p}_i\}_{i=1}^{N}$, rays are traced from $\mathbf{o}$ through the voxel grid along the direction of each scanned point. For each ray, voxels along the path are classified into three categories:

\begin{enumerate}
    \item \textbf{Observed empty}: voxels that the ray passes through before hitting a surface. These voxels are confirmed to contain no geometry.
    \item \textbf{Occupied}: voxels that contain scanned points. These voxels are confirmed to contain geometry.
    \item \textbf{Occluded}: voxels that lie behind an occupied voxel along the ray direction. These voxels could not be observed by the scanner and may or may not contain geometry.
\end{enumerate}

For a ray from $\mathbf{o}$ to a scanned point $\mathbf{p}_i$, the ray direction is defined as:

\begin{equation}
    \label{eq:5_ray_direction}
    \mathbf{d}_i = \frac{\mathbf{p}_i - \mathbf{o}}{\|\mathbf{p}_i - \mathbf{o}\|}
\end{equation}

The discrete traversal through the voxel grid is performed using a 3D variant of the Bresenham line algorithm, which efficiently identifies all voxels intersected by each ray. Voxels along the ray before the intersection with the surface at $\mathbf{p}_i$ are marked as observed empty, the voxel containing $\mathbf{p}_i$ is marked as occupied, and voxels beyond $\mathbf{p}_i$ along the ray direction are marked as occluded.

Voxels that are not traversed by any ray remain in an unknown state and are also treated as potentially occluded. When multiple scanner positions are available, the voxel classification is accumulated across all positions: a voxel that is occluded from one scanner position but observed empty from another is classified as empty, since at least one observation confirms the absence of geometry.

The voxel resolution directly controls the trade-off between spatial precision and computational cost. A finer resolution produces more accurate occlusion maps but requires more memory and processing time. The impact of this trade-off is evaluated experimentally in Section~\ref{sec:5_exp_occlusion}.

\subsubsection{Scene-Level Occlusion}
\label{sec:5_scene_occlusion}

At the scene level, the voxel grid spans the entire room volume. The ray marching is performed using all scanned points (before object removal) from all available scanner positions. The resulting occlusion grid classifies every voxel in the room as observed empty, occupied, or occluded.

This scene-level occlusion grid serves the scene completion stage (Chapter~\ref{ch:6_Scene_Completion}) by identifying where new geometry could plausibly exist. Specifically, the scene completion method can use the occlusion grid to constrain its reconstruction: new geometry should only be generated in voxels classified as occluded, not in voxels that have been confirmed as empty by direct observation. This prevents the completion from hallucinating geometry in regions where the scanner has already confirmed the absence of surfaces.


% ── 5.3.2.3 ──────────────────────────────────────────────────────────────────
\subsubsection{Object-Level Occlusion}
\label{sec:5_object_occlusion}

At the object level, the voxel grid is defined within each object's \gls{OBB}. The use of oriented bounding boxes is important: because the bounding box is aligned with the object's principal axes rather than the world axes, the resulting voxel grid provides a more efficient and meaningful discretisation of the object's volume.

For each detected object, rays are traced from the scanner position(s) through the object-level voxel grid. The classification follows the same three-category scheme as the scene level, but is restricted to the volume enclosed by the oriented bounding box. The resulting per-object occlusion grid indicates which portions of each object were visible to the scanner and which were hidden.

This object-level occlusion information serves the object completion stage (Chapter~\ref{ch:7_Object_Completion}) in two ways. First, it provides an initial estimate of which voxels need to be completed by the generative model, separating the observed geometry from the regions requiring prediction. Second, when combined with the symmetry detection from the bounding box refinement step, the occluded voxels on one side of the symmetry plane can be initialised with mirrored values from the observed side, providing a geometric prior for the completion network~\cite{vermandere_guided_2025}.

\section{Experiments}
\label{sec:5_experiments}

The experimental evaluation is divided into three parts, corresponding to the three main components of the methodology: object detection, symmetry detection, and occlusion detection. All experiments on object detection and occlusion detection are conducted on the V-Scan synthetic dataset (Section~\ref{sec:3_vscan}), which provides both partial scans and complete ground-truth geometry including ground-truth bounding boxes. The symmetry detection is evaluated independently on partial scans from the ShapeNet dataset~\cite{chang_shapenet_2015}.


% ─────────────────────────────────────────────────────────────────────────────
\subsection{Object Detection}
\label{sec:5_exp_detection}

The object detection pipeline is evaluated on the V-Scan dataset across all five environment types. Since the V-Scan dataset provides ground-truth bounding boxes corresponding to the complete objects, the evaluation measures both detection accuracy and the quality of the spatial extent estimation.

\subsubsection{Evaluation Protocol}

The detection is evaluated using precision, recall and \gls{IoU} between predicted and ground-truth bounding boxes. A predicted bounding box is considered a true positive when it overlaps sufficiently with a ground-truth box. Precision measures the fraction of predicted boxes that correspond to real objects, recall measures the fraction of ground-truth objects that are detected, and the average IoU quantifies the spatial accuracy of the matched detections.

\subsubsection{Analysis}

Several observations can be drawn from these results. The overall precision of 0.310 indicates that a substantial number of false positive detections occur across all environment types. This is partly expected, since the detector was originally trained on real-world datasets (ScanNet, SUN RGB-D) and applied here to synthetic V-Scan data, introducing a domain gap. Additionally, the over-detection tendency of VoteNet in densely furnished scenes, previously noted in~\cite{vermandere_guided_2025}, contributes to the lower precision despite the IoU-based merging of overlapping boxes.

Recall varies considerably across environment types. The bedroom and living room categories achieve the highest recall (0.681 and 0.678 respectively), which can be attributed to the presence of larger, more geometrically distinct objects such as beds, sofas and tables. The industrial environment shows the lowest recall (0.364), likely due to the presence of smaller or more irregularly shaped objects that are harder to detect from a single scan position.

The average IoU across all scenes is 0.517, indicating moderate spatial overlap between predicted and ground-truth bounding boxes. Since the ground-truth boxes correspond to the complete objects while the predicted boxes are fitted to the visible geometry, the IoU is inherently limited by the degree of occlusion in each scene. The bounding box refinement step described in Section~\ref{sec:5_bb_refinement} aims to improve this overlap, and its impact is discussed further in the context of the completion results in Chapter~\ref{ch:7_Object_Completion}.

The effectiveness of the plane detection for bounding box refinement depends on the positioning of objects relative to the room structure. When an object is not positioned against a wall, the impact is minimal, as the only relevant plane is the floor. Since the initial detection bounding boxes are aligned with the global axis, and the floor is typically level, the bounding box aligns naturally with the floor. However, for objects positioned against a wall, especially when the walls do not align with the global orthogonal axis, the additional plane provides a clear initial alignment and physical boundary for the object~\cite{vermandere_guided_2025}.

\subsection{Symmetry Detection}
\label{sec:5_exp_symmetry}

The symmetry detection component is evaluated independently on partial scans of single objects from the ShapeNet dataset~\cite{chang_shapenet_2015}. For each object, a partial scan is simulated by removing geometry beyond a randomly oriented clipping plane, mimicking the one-sided observations typical of indoor scanning.

\subsubsection{Evaluation Protocol}

The evaluation is performed on 100 chair models from the ShapeNet dataset. For each model, up to three symmetry axes are detected and ranked by confidence score. The detected symmetry planes are compared against the ground-truth symmetry planes of the complete object. The evaluation metrics include the angular error between the detected and ground-truth symmetry plane normals, and the detection rate (the fraction of shapes for which the correct symmetry axis was found within a tolerance).

\subsubsection{Results}

Table~\ref{tab:5_symmetry_results} reports the symmetry detection results on the ShapeNet chair category.

\subsubsection{Analysis}

The primary symmetry axis, which is most important for the bounding box refinement, is detected with high reliability: a 94.0\% detection rate and a mean angular error of only $8.01^{\circ}$. This is encouraging because the primary axis is the one used to define the ``right'' vector of the oriented bounding box, and a small angular error translates to a well-aligned bounding box.

The secondary and tertiary axes are detected less reliably, with detection rates of 70.0\% and 78.0\% and substantially higher angular errors. This is expected for partial observations: with an average visibility fraction of only 36.5\% of the full geometry, many of the geometric features that define the secondary and tertiary symmetry planes are simply not present in the partial scan. The higher detection rate of the tertiary axis (78.0\%) compared to the secondary (70.0\%) may be explained by the particular geometry of chairs, where the vertical symmetry is often more robust to partial observation than the front-back symmetry.

The symmetry detection scores also show a decrease from full to partial observations (0.355 to 0.297 mean score), confirming that the confidence of the detected symmetries decreases when less geometry is available. Despite this reduction, the primary axis remains sufficiently reliable for the bounding box refinement, since even a moderate angular error can be partially compensated by the boundary limiting step that uses the scene planes.

\subsection{Occlusion Detection}
\label{sec:5_exp_occlusion}

The occlusion detection is evaluated using the V-Scan synthetic dataset (Section~\ref{sec:3_vscan}), which provides both the partial scans and the complete ground-truth geometry.

\subsubsection{Ground Truth Generation}

The ground truth for the occlusion grid is derived from the difference between the furnished and empty scene panoramic images available in the V-Scan dataset. For each pixel in the panoramic image, the corresponding 3D coordinates in the furnished and empty scenes are compared. Pixels where the depth differs significantly correspond to regions where an object was present in the furnished scene, and the space behind those objects is labelled as occluded. The 3D coordinates of the occluded voxels are then checked against the voxelised occlusion grid produced by the ray marching algorithm.

\subsubsection{Analysis}

The occlusion statistics reveal several patterns about the relationship between scene type and scanner visibility. The occupied percentage, which represents the fraction of the voxel grid containing scanned surface geometry, ranges from 18.70\% for the industrial scenes to 31.08\% for the bedrooms. The bedroom scenes have a higher occupied fraction because they are physically smaller rooms (lower total voxel count of 8,405 on average) with proportionally more furniture filling the volume.

The occluded percentage shows substantial variation both across and within environment types. The dining room scenes exhibit the highest mean occlusion at 22.07\%, but also the highest standard deviation (26.01\%), indicating that the occlusion level depends strongly on the particular furniture arrangement in each scene. Scenes where chairs are clustered tightly around a central table create large shadow regions behind the furniture that are hidden from the scanner, while more open arrangements leave most of the room visible. Similarly, the industrial scenes show high variability (13.03\% standard deviation) due to the diverse configurations of shelving and equipment that can either block or expose large volumes depending on their placement relative to the scanner position.

The office environments show the most consistent and lowest occlusion levels (7.97\% $\pm$ 5.97\%), which is likely explained by the more regular and open layout typical of office spaces, where desks and chairs are spaced apart rather than tightly clustered.

These statistics have direct implications for the downstream completion stages. Scenes with higher occlusion percentages present more challenging completion problems, as a larger fraction of the environment must be reconstructed from the occlusion prior alone. The high variability within each class also highlights the importance of the dual-level approach: the scene-level grid captures the broad spatial structure of the occlusion pattern, while the object-level grids provide the detailed per-object masks needed for targeted completion.

\section{Conclusion}
\label{sec:5_conclusion}

This chapter presented the object isolation and occlusion detection methodology that bridges the gap between the aligned point cloud produced in Chapter~\ref{ch:4_Alignment_Updating} and the completion stages presented in Chapters~\ref{ch:6_Scene_Completion} and~\ref{ch:7_Object_Completion}.

The object isolation pipeline begins with an iterative RANSAC-based plane segmentation that identifies and removes the structural elements of the scene (walls, floors and ceilings), both to simplify the subsequent detection and to provide the physical boundary constraints needed for bounding box refinement. Object detection is then performed on the cleaned foreground point cloud using a VoteNet-based detector~\cite{qi_deep_2019}, achieving an overall precision of 0.310, recall of 0.485 and average IoU of 0.517 across 200 V-Scan scenes. The detected bounding boxes are subsequently refined through a two-step procedure. First, approximate symmetry detection~\cite{sipiran_approximate_2014} identifies the primary axis of each partial object with a mean angular error of $8.01^{\circ}$ and a 94.0\% detection rate. Second, the symmetry axis is combined with the scene planes to construct an oriented bounding box whose extent is constrained by the physical boundaries of the room~\cite{vermandere_guided_2025, korman_latent_2018}.

The occlusion detection methodology uses voxelised ray marching from the known scanner positions to classify the scene volume into observed empty, occupied and occluded regions. By operating at both scene level and object level simultaneously, the approach provides the spatial priors needed by both the scene completion stage, which needs to know where environmental geometry could plausibly exist, and the object completion stage, which needs to know which parts of each object were hidden from the scanner. The occlusion analysis on the V-Scan dataset revealed that the fraction of occluded volume varies substantially across and within environment types, ranging from 7.97\% for office scenes to 22.07\% for dining rooms, with high intra-class variability reflecting the strong dependence on furniture arrangement and scanner placement.

Several limitations should be noted. First, the quality of the object isolation depends directly on the accuracy of the initial object detection. The moderate precision (0.310) means that a considerable number of false positive detections occur, and missed detections propagate as errors into all subsequent stages since objects that are not detected cannot be completed or dynamified. The domain gap between the training data (real-world scans) and the evaluation data (synthetic V-Scan scenes) likely contributes to the lower precision, and fine-tuning the detector on synthetic data or using more recent architectures could improve these results. Second, the symmetry-based bounding box refinement assumes that objects exhibit at least one axis of symmetry, which holds for the majority of manufactured indoor furniture but may not apply to irregular or asymmetric objects. While the primary axis is detected reliably (94.0\%), the secondary and tertiary axes show substantially lower detection rates and higher angular errors, limiting the refinement for objects whose alignment depends on these additional axes. Third, the voxel resolution in the occlusion detection introduces a fundamental trade-off between spatial precision and computational cost, and the optimal resolution depends on the scale and complexity of the scene.

Despite these limitations, the outputs of this chapter, consisting of isolated partial objects with refined oriented bounding boxes and dual-level occlusion grids, provide the structured inputs required for the parallel scene and object completion stages that follow. The scene-level occlusion grid informs Chapter~\ref{ch:6_Scene_Completion} about where environmental reconstruction is needed, while the per-object occlusion grids and refined bounding boxes provide Chapter~\ref{ch:7_Object_Completion} with the spatial context and geometric priors necessary for plausible object reconstruction.
